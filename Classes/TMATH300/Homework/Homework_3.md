We will prove this using a proof by contradiction, suppose the square root of any natural number is a rational number, but not an integer. This means that $\sqrt{ n }=\frac{a}{b}$ where $a$ and $b$ are positive integers with no common factors. Squaring both sides gives us $n=\frac{a^2}{b^2}$, or $nb^2=a^2$. If $b$ is $1$ then $n=a^2\implies \sqrt{ n }=a$, making $\sqrt{ n }$ an integer. If $b\neq 1$ then $nb^2=a^2\implies \sqrt{ n }b=a$ making $\sqrt{ n }$ a factor of a.

We will utilize a contrapositive proof, that is, we will prove that if the square root of a number is not an integer and not irrational, the number is not natural.
